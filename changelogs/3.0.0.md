**First release for Minecraft 26.2.** An unofficial fork of
[Chest Tracker](https://modrinth.com/mod/chest-tracker) by
[JackFred](https://modrinth.com/user/JackFred) — not affiliated with or endorsed by him. If the
original updates to 26.x, use it instead.

In game the mod is still called **Chest Tracker**.

---

## ⚠️ Read before installing

**Remove these two mods first — the game will refuse to load otherwise:**

| Remove | Why |
|---|---|
| **Where Is It** | Its search and in-world highlighting are now built in |
| **Chest Tracker** (original) | This replaces it |

Both are enforced with a `breaks` declaration, so you'll get a clear error rather than strange
behaviour if one is left installed.

**Your data carries over.** Memory banks still load from `<game dir>/chesttracker/` and config from
`<config dir>/chesttracker.json5` — both paths unchanged, so everything you've collected survives
the upgrade.

## Requirements

- Minecraft **26.2** · Fabric · **Java 25**
- [Fabric API](https://modrinth.com/mod/fabric-api) and [YACL](https://modrinth.com/mod/yacl) 3.9.0+

---

## Improvements over the original

- Highlights now **pulse** in size and opacity, so they're much easier to pick out
- Highlights are **translucent** instead of fully opaque, so you can still see the container
- Highlights last **12 seconds** instead of 5, holding full brightness before fading
- **One jar instead of three** — Where Is It and JackFredLib are no longer separate downloads

## Ported to 26.2

Minecraft 26.x is the first fully unobfuscated release, and 1.21.9 replaced immediate-mode GUI
drawing with a deferred render-state model. Getting from 1.21.4 to 26.2 meant rewriting the whole
GUI layer, the in-world renderer, and all input handling.

Built against Fabric Loader 0.19.3, Fabric API 0.156.0, Java 25.

## Removed

No 26.x builds exist upstream for these integrations:

- **Litematica / MaLiLib** — material-list search buttons
- **Expanded Storage** — extra container support

## Known limitation

**Highlights don't show through walls.** The original disabled depth testing so containers hidden
behind terrain stayed visible. Minecraft 26.2 removed the rendering path that allowed it, and
restoring the behaviour needs a custom render pipeline. Planned for a later release.
